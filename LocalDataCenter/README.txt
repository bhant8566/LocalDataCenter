Local Data Center｜分檔版

1. 複製 LocalDataCenter.ps1 和整個 web 資料夾，保持相對位置。
2. 在公司主機的 Windows PowerShell 確認 ImportExcel 可以載入。
       Import-Module ImportExcel
3. 用 PowerShell 進入上述資料夾，執行 .\LocalDataCenter.ps1。
   結束時在 PowerShell 視窗按 Ctrl+C。

LocalDataCenter.ps1   PowerShell 後端
web/index.html       網頁結構
web/app.css          版面樣式
web/app.js           前端互動
web/features.js      表格、Excel 預覽、搬移、搜尋與 OCR 流程
web/vendor/          PDF、OCR、模型、字型和授權資訊。請保留子資料夾。

程式預設讀寫桌面下 LocalDataCenter 資料夾內的 Excel 與 Attachments。
如果已使用過同一個資料夾，先關閉舊版視窗，再啟動這版。

月曆會直接顯示在右側工具區下方，可切換月份，並標示今日。
每筆事件標題旁有「進行中／已結束」開關，點擊即儲存狀態，亦可將已結束事件改回進行中。
事件紀錄上方可篩選進行中、已結束或全部；預設顯示全部。進行中為綠色，已結束為灰色。
更新檔案後必須停止並重新啟動 PowerShell 服務。若網頁連到舊服務，會顯示提醒並暫停寫入，避免狀態或多組時程被忽略。
舊事件預設視為進行中，狀態儲存在 Excel 的 Content 工作表，不需要更改表頭。
事件編輯視窗可按「移除事件」，確認後移除該事件及其時程，以及無其他引用的附件原檔。尚未儲存的新事件可按「取消新增」。
展開事件後，上方案件時程會顯示該事件的所有時程。編輯事件時可新增、修改、移除時程。
每條時程等寬，淡色表示完整期間，實色按各自期間已經過的百分比填滿，不顯示百分比數字，並非工作完成度。
點擊單條時間條可開啟獨立編輯視窗，修改時程名稱、起訖日期、文字說明，加入圖片與附件。
請先手動選完成日期，再切換「已完成」並儲存。完成後時間條填滿綠色，倒數改為「某月某日已完成」。
切回未完成會清空完成日期並恢復時間倒數，文字、圖片與附件會保留；這不會改變所屬事件的狀態。
時程文字與圖片直接顯示在時間條下方，附件圖示位於完成狀態與日期文字左邊。點擊時間條可修改完成日期，或透過未完成開關開啟編輯視窗。
不顯示共用日期軸或背景刻度；日期與剩餘天數仍保留。剩餘少於 5 日為紅色，5 至 9 日為橘色，10 日以上為綠色。
結束日當天顯示「今日到期」，當天結束才走滿；隔天顯示「已逾期 1 日」。
倒數依電腦本機日期計算，每分鐘及切回頁面時更新，不會定時向後端請求資料。

附件圖示位於事件本文下方，點擊可預覽圖片、PDF（連續捲動）、Excel 與 UTF-8 純文字。
點擊預覽視窗外的遮罩、關閉按鈕或按 Esc，皆可關閉預覽並返回原編輯視窗。
純文字支援 txt、csv、log、md、json、xml、yaml、yml、ini；其他格式或預覽失敗時可下載原檔。
Excel 支援 xls、xlsx，預覽上方列出所有工作表分頁，可點選或用方向鍵切換，顯示合併格與原檔儲存的數字、日期及公式結果；不重新計算公式，不還原圖表或完整樣式。
PDF 依捲動位置繪製頁面；已有文字層的 PDF 可選取複製文字，純掃描頁需先經 OCR。
舊附件還原後若無法預覽，請查看預覽視窗的完整錯誤。找不到原檔時會顯示程式實際尋找的路徑，請確認 Attachments 放在啟動時的 DataRoot 下，沒有多包一層資料夾，並保留原始檔名。
一般附件以識別碼加 .bin 保存屬正常設計，不必自行改成 .pdf。UTF-8 僅適用純文字，不是 PDF 的預覽要求。
圖片仍為原檔上傳，未壓縮；附件預覽全程在本機處理。

表格操作：平常左鍵可編輯文字；按住 Shift，再從任意儲存格內按住左鍵拖曳，選取矩形範圍。拖到編輯區邊緣會自動捲動，放開滑鼠後保留選取。
在選取的格子上按右鍵，選「合併儲存格」或「分割儲存格」；框選碰到合併格時會自動納入整個合併格。無法使用的操作會呈現停用狀態，Esc 可關閉選單。
事件顯示、事件編輯及 Excel 預覽中的寬表格不會因視窗較窄而強制換行，可使用底部水平捲動條。
Excel 預覽視窗內，或事件本文、編輯區內，同時按住滑鼠左右鍵再左右移動，可水平拖移；放開任一鍵即停止。單獨按右鍵仍保留選單操作。
文字顏色改為固定色盤，提供標準色、淺色與灰階；可對反白文字、游標後續輸入或已框選的儲存格套用顏色。
「分割儲存格」還原合併格，內容保留在左上格。Excel 複製貼上保留表格、合併格、底色、字色及對齊。
貼到既有表格時從游標所在格開始填入，必要時擴充列欄；覆蓋內容或分割跨界合併格前會先確認。
事件搜尋只搜尋目前分頁的標題、本文、時程名稱與說明及附件檔名，並與狀態篩選共同生效，不搜尋附件內文。
事件標題旁的拖曳把手可將事件移到同專案的其他分頁，搬移後切至目標分頁，仍依日期由新到舊排列。
專案與分頁的「修改」視窗可改名或移除；移除前顯示影響數量，確認後連同底下事件、時程與無其他引用的附件一起刪除。
事件與時程編輯中的附件「移除」會先修改草稿，儲存成功後才刪除 Attachments 的原檔；取消編輯不刪除已儲存的附件。
附件仍被其他事件、時程或本文圖片使用時不刪原檔；刪檔失敗會明確提示資料已儲存但原檔未刪除。
previous.xlsx 僅備份上一版 Excel，不備份附件；刪除附件原檔後無法單靠該 Excel 還原附件。

OCR 可選一份 PDF（全部頁面）或多張圖片，圖片順序可在清單中調整；辨識支援繁體中文與英文。
掃描 PDF 固定以 300 DPI 產生辨識影像，不限制為 3500 像素長邊；原 PDF 頁面外觀、尺寸與旋轉方向保留。圖片輸入的縮放規則及語言模型維持原設定。
提高解析度會增加 CPU 運算與記憶體需求；超大頁面若無法建立畫布，會顯示該頁錯誤，不會自行降低 DPI。
辨識期間顯示頁碼與進度；失敗後按「重試未完成頁面」從失敗頁繼續，完成前不提供完整 PDF 輸出。
結果保留原頁面外觀並加入可選取的文字層，可預覽、下載可搜尋 PDF；純文字可另行校對及插入事件。
純文字校對不會修改 PDF 內的辨識文字層。
從事件編輯器開啟 OCR 時顯示目標事件，加入 PDF 後返回原編輯器確認儲存。
從右側工具開啟 OCR 時，可選專案、分頁，再選新增或既有事件；結果在切換及取消選擇時保留。
OCR 產生的 PDF 仍適用單檔 25 MB 上傳限制；未儲存的上傳檔不會掃除，既有歷史孤立附件也不會批次清除。
程式隨附 SheetJS 0.20.3 與授權檔，執行時不需上網。

既有 Excel 的單組日期會轉為「原有時程」。多組時程儲存在 Content 工作表中，需使用新版程式編輯以保留多組資料。

驗證（使用獨立暫存資料，不修改正式 Excel）：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-UI.ps1
驗證事件狀態、時程內容、圖片與文字預覽及版面（略過 PDF 等完整附件回歸）：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-UI.ps1 -StatusOnly
只執行完整 OCR 回歸（含實際引擎、多頁、失敗重試與加入事件）：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-UI.ps1 -OCROnly
驗證實體檔被鎖住時的刪除提示及本文圖片引用保護：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-Storage.ps1
使用舊 PDF 的副本驗證預覽（不修改原檔，-PreviewPdf 也可指定實際為 PDF 的 .bin）：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-UI.ps1 -PreviewPdf '附件原檔的完整路徑'
UI 測試需要本機 Microsoft Edge，測試結束會關閉測試用服務與瀏覽器，截圖保留於輸出的暫存目錄。
