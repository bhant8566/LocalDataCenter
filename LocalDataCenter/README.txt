Local Data Center｜分檔版

1. 複製 LocalDataCenter.ps1 和整個 web 資料夾，保持相對位置。
2. 在公司主機的 Windows PowerShell 確認 ImportExcel 可以載入。
       Import-Module ImportExcel
3. 用 PowerShell 進入上述資料夾，執行 .\LocalDataCenter.ps1。
   結束時在 PowerShell 視窗按 Ctrl+C。

LocalDataCenter.ps1   PowerShell 後端
web/index.html       網頁結構
web/app.css          版面樣式
web/app.js           前端互動
web/vendor/          PDF、OCR、模型、字型和授權資訊。請保留子資料夾。

程式預設讀寫桌面下 LocalDataCenter 資料夾內的 Excel 與 Attachments。
如果已使用過同一個資料夾，先關閉舊版視窗，再啟動這版。

月曆會直接顯示在右側工具區下方，可切換月份，並標示今日。
每筆事件標題旁有「進行中／已結束」開關，點擊即儲存狀態，亦可將已結束事件改回進行中。
事件紀錄上方可篩選進行中、已結束或全部；預設顯示全部。進行中為綠色，已結束為灰色。
更新檔案後必須停止並重新啟動 PowerShell 服務。若網頁連到舊服務，會顯示提醒並暫停寫入，避免狀態或多組時程被忽略。
舊事件預設視為進行中，狀態儲存在 Excel 的 Content 工作表，不需要更改表頭。
事件編輯視窗可按「移除事件」，確認後移除該事件及其時程；已上傳的附件原檔會保留。尚未儲存的新事件可按「取消新增」。
展開事件後，上方案件時程會顯示該事件的所有時程。編輯事件時可新增、修改、移除時程。
每條時程等寬，淡色表示完整期間，實色按各自期間已經過的百分比填滿，不顯示百分比數字，並非工作完成度。
點擊單條時間條可開啟獨立編輯視窗，修改時程名稱、起訖日期、文字說明，加入圖片與附件。
請先手動選完成日期，再切換「已完成」並儲存。完成後時間條填滿綠色，倒數改為「某月某日已完成」。
切回未完成會清空完成日期並恢復時間倒數，文字、圖片與附件會保留；這不會改變所屬事件的狀態。
時程文字與圖片直接顯示在時間條下方，附件圖示位於完成狀態與日期文字左邊。點擊時間條可修改完成日期，或透過未完成開關開啟編輯視窗。
不顯示共用日期軸或背景刻度；日期與剩餘天數仍保留。剩餘少於 5 日為紅色，5 至 9 日為橘色，10 日以上為綠色。
結束日當天顯示「今日到期」，當天結束才走滿；隔天顯示「已逾期 1 日」。
倒數依電腦本機日期計算，每分鐘及切回頁面時更新，不會定時向後端請求資料。

附件圖示位於事件本文下方，點擊可預覽圖片、PDF（可換頁）與 UTF-8 純文字。
點擊預覽視窗外的遮罩、關閉按鈕或按 Esc，皆可關閉預覽並返回原編輯視窗。
純文字支援 txt、csv、log、md、json、xml、yaml、yml、ini；其他格式或預覽失敗時可下載原檔。
圖片仍為原檔上傳，未壓縮；附件預覽全程在本機處理。

既有 Excel 的單組日期會轉為「原有時程」。多組時程儲存在 Content 工作表中，需使用新版程式編輯以保留多組資料。

驗證（使用獨立暫存資料，不修改正式 Excel）：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-UI.ps1
驗證事件狀態、時程內容、圖片與文字預覽及版面（略過 PDF 等完整附件回歸）：
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-UI.ps1 -StatusOnly
UI 測試需要本機 Microsoft Edge，測試結束會關閉測試用服務與瀏覽器，截圖保留於輸出的暫存目錄。
